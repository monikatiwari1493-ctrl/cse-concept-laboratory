Step 1 — Problem

A network made a mistake. Which connections should change?

Imagine a tiny neural network that receives a few numbers and produces one answer. Its current answer is not quite right. You can change the connections between the neurons, but the challenge is knowing which connection should change and in which direction.

Your challenge

Can you get the network's output close to its target with as few changes as possible?

Step 2 — Setup

Meet the tiny network

  • Inputs: two values enter the network and flow from left to right.
  • Weights: six connections control how strongly information travels.
  • Your job: move the six weight sliders until the output is within 0.03 of the target.
  • Feedback: the output and loss update after every move.
  • Direction hint: see whether each weight should go up or down. A hint costs 5 points.
  • Backprop step: let the computed gradients move all six weights automatically.
  • Scoring: fewer manual moves and fewer hints produce a better score.
Important

Do not worry about the name of the algorithm yet. First observe what information helps you decide how to change a weight.

Step 5 — Concept

Now name it — Backpropagation

Key idea

Definition

Backpropagation is the algorithm used to efficiently compute how the loss changes with respect to each weight in a neural network. It sends an error signal backward through the network using the chain rule of calculus.

Mechanism

1. Run a forward pass to produce an output.
2. Compare the output with the target using a loss function.
3. Propagate the error backward from the output toward earlier layers.
4. Compute a gradient for every weight.
5. Give those gradients to an optimizer such as gradient descent to update the weights.

Vocabulary

Loss — how wrong the prediction is.   Gradient — direction and rate of change of loss.   Chain rule — combines local derivatives through a sequence of operations.   Learning rate — controls how large an update is.

Without useful gradients Try weights blindly and repeatedly measure the result.
With backpropagation Compute how each weight contributes to the loss, then update weights in the useful direction.

What the game was calculating

For the output neuron:

δo = (o − t) · o(1 − o)

For a hidden neuron:

δh = δo · w · h(1 − h)

Then each weight receives a gradient and can be updated:

w ← w − η · ∂L/∂w

The game showed these gradients as arrows. That is why the hint could tell you whether to raise or lower each weight.

Important distinction

Backpropagation computes gradients. An optimizer such as gradient descent uses those gradients to change the weights. They work together, but they are not the same thing.

Transfer

Think about a real neural network: the same basic backward-gradient idea can be repeated across many layers and many training examples. Modern optimizers add improvements, but the central learning signal still comes from these gradients.
