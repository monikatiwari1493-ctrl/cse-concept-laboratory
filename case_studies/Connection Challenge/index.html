System Anatomy

Meet the Tiny Network

Here is the anatomy of the minimal multi-layer neural network you will encounter across machine learning:

  • Input Neurons ($x_1, x_2$): Fixed input values. They do not have weights; they pass data forward.
  • Hidden Neurons ($h_1, h_2$): Compute a weighted sum $z = \sum w_i x_i$, then pass it through a non-linear activation function $\sigma(z) = \frac{1}{1 + e^{-z}}$.
  • Output Neuron ($o$): Combines hidden signals into a single output prediction $\sigma(w_5 h_1 + w_6 h_2)$.
  • Credit Assignment Problem: When the output is wrong, how much responsibility belongs to $w_1$ vs $w_5$? Backpropagation calculates this exactly.

Under the Hood

The Mathematics of Backpropagation

1. Output Neuron Error Signal ($\delta_o$):

δo = (o − t) · o(1 − o)

2. Hidden Neuron Error Signal via Chain Rule ($\delta_h$):

δh = δo · w_output · h(1 − h)

3. Gradient for Any Weight ($\frac{\partial L}{\partial w}$):

∂L/∂w = δ · (input to connection)

4. Gradient Descent Weight Update Rule:

w ← w − η · (∂L/∂w)

The direction arrows you saw indicate $-\frac{\partial L}{\partial w}$. If the gradient is negative, increasing the weight reduces loss ($\uparrow$); if positive, decreasing the weight reduces loss ($\downarrow$).

Without Backpropagation (Trial & Error) Tweaking one weight at a time requires re-running the entire network thousands of times—computationally impossible for real networks with billions of weights.
With Backpropagation (Analytical Chain Rule) Computes the exact gradient for all millions of weights simultaneously in a single backward sweep from output to input.
Key Takeaway

Backpropagation computes gradients; an optimizer (such as Gradient Descent) uses those gradients to change the weights. They work together, but they perform distinct roles.

Real-World Transfer

Whether in a 6-parameter toy network or a 500-billion-parameter language model, the principle is identical: forward pass to calculate predictions and loss, followed by backward propagation of errors to tell every parameter how to improve.
